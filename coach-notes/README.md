# Coach's notes

Markdown files in this directory form the draft coach's knowledge base. Every
`.md` file here (except this README) is loaded into the coach's context each
time you send it a message, so it can apply your strategy, league quirks, and
player takes when reviewing drafts.

Suggestions:

- One topic per file, e.g. `draft-strategy.md`, `league-tendencies.md`,
  `player-takes.md`.
- Keep notes short and declarative — the coach reads them verbatim.
- Up to 12 notes are sent, each capped at 6,000 characters.

The dev server picks up new files automatically; restart `npm run dev` if a
brand-new file does not appear.
